Guard Models Are Overconfident Where Base Models Are Uncertain


datumo safety team
EMNLP 2026

Abstract

가드 모델이 유해한 요청을 높은 확신으로 안전하다고 판단한다면, 확신도만으로 그 오류를 걸러낼 수 있을까? 이 연구는 다섯 가드 모델의 안전성 분류를 분석해, 일반 입력에서 잘 보정된 확신도도 적대적 공격 아래에서는 크게 어긋날 수 있음을 보인다.

가드 모델이 놓친 유해 입력에 대해 대응하는 base 모델은 대체로 더 높은 불확실성을 보였다. 두 모델의 차이는 네트워크 후반부에서 커졌고, 가드 모델의 낮은 유효 랭크와 뚜렷한 safe/unsafe 표현 분리가 함께 관찰됐다. 안전성 탐지 정확도와 함께, 공격 상황에서도 확신도를 신뢰할 수 있는지 평가해야 한다는 것이 핵심 메시지다.

Background

가드 모델은 사용자 입력이 안전한지 판단해 요청을 통과시키거나 차단하는 안전장치다. 이때 분류 결과뿐 아니라 확신도를 기준으로 판단을 보류하거나 추가 검토를 요청할 수 있다. 하지만 이런 방식이 효과를 내려면 높은 확신이 실제 정답률과 맞아야 한다.

이 연구는 유해한 내용을 안전하다고 잘못 분류하는 미탐(false negative, FN)에 주목한다. 공격으로 판단이 흔들렸는데도 확신도가 높게 유지된다면, 불확실한 입력만 재검토하는 방식으로는 이러한 오류를 잡기 어렵다.

Experimental Setup

실험은 사용자 프롬프트의 safe/unsafe 분류를 중심으로 구성했다.

  • 모델: Llama-Guard 7B, Llama-Guard-2 8B, Llama-Guard-3 8B, WildGuard 7B, ShieldGemma 9B와 각각의 base 모델을 비교했다.
  • 일반 입력: HarmBench·StrongREJECT의 유해 프롬프트 713개와 Alpaca의 무해 프롬프트 500개, 총 1,213개를 사용했다.
  • 적대적 입력: GCG, AutoDAN, TAP, PAIR, AutoDAN-Turbo, TextGrad 기반 자체 공격을 적용한 유해 프롬프트 3,965개를 사용했다.
  • 측정: 두 판정 라벨에 제한한 softmax로 확률을 계산하고, 예측 라벨의 확률을 확신도로 정의했다. 확신도와 실제 정답률의 차이는 ECE(Expected Calibration Error)로 평가했다. ECE는 낮을수록 좋다.

가드 모델에는 공식 안전 지침과 템플릿을, base 모델에는 5-shot 분류 프롬프트를 사용했다. 두 라벨로 정규화한 확신도는 전체 어휘에 대한 생성 확률과는 다르다.

Results

일반 입력의 보정 성능은 공격 상황으로 이어지지 않는다

그림 1. 일반 입력(위)과 적대적 입력(아래)의 reliability diagram. 붉은 영역은 확신도가 실제 정답률보다 높은 구간이다. 원문 Figure 1.

가드 모델 일반 입력 ECE 적대적 입력 ECE
Llama-Guard 7B 0.142 0.578
Llama-Guard-2 8B 0.045 0.405
Llama-Guard-3 8B 0.013 0.308
WildGuard 7B 0.004 0.196
ShieldGemma 9B 0.325 0.684

일반 입력에서 보정 오차가 작았던 Llama-Guard-3와 WildGuard도 공격 상황에서는 ECE가 크게 증가했다. 이는 공격이 단순히 모델을 불확실하게 만드는 데 그치지 않고, 높은 확신을 동반한 오판을 유발한다는 결과다.

원문 Figure 2에서는 확신도 기준을 0.99로 높여도 전체 적대적 유해 입력 중 Llama-Guard-3는 11%, WildGuard는 12%, ShieldGemma는 37%를 높은 확신으로 안전하다고 잘못 분류했다. 이 비율의 분모는 모델별 미탐 수가 아니라 전체 적대적 유해 입력 3,965개다. 정탐과 미탐의 확신도 분포가 겹쳐, 확신도 임계값만으로 미탐을 선택적으로 제거하기 어렵다.

가드가 놓친 입력에도 base 모델의 불확실성은 남아 있다

그림 2. 가드 모델이 유해 입력을 안전하다고 잘못 분류한 사례에서의 엔트로피 차이 ΔH = H(base) - H(guard). 양수이면 base 모델이 더 불확실하다. 원문 Figure 4.

가드의 미탐 사례 중 base 모델의 엔트로피가 더 높은 비율은 Llama-Guard-2에서 82%, Llama-Guard-3에서 80%, WildGuard에서 93%였다. ShieldGemma는 51%로, 같은 경향이 뚜렷하지 않았다.

이 결과는 가드의 높은 확신만 보면 놓치는 신호가 대응 base 모델에는 남아 있을 수 있음을 보여준다. 더 높은 엔트로피가 곧 올바른 분류를 뜻하는 것은 아니다. 또한 Llama-Guard 7B/Llama-2 7B 쌍은 base 모델의 강한 unsafe 예측 편향 때문에 후속 대응 분석에서 제외했다.

Representation Analysis

그림 3. 초기·후기 층에서 일반 무해 입력(파랑), 일반 유해 입력(빨강), 적대적 유해 입력(초록)의 은닉 표현. 각 패널에 PCA를 독립적으로 적용했으므로 패널 간 좌표를 직접 비교해서는 안 된다. 원문 Figure 6.

층별 분석에서는 base 모델이 유해하다고 맞히고 가드는 안전하다고 틀린 적대적 입력에 대해, 가드가 부여하는 unsafe 확률이 base 모델보다 낮아지는 차이가 후반부에서 커졌다(원문 Figure 5).

가드의 후기 표현에서는 일반 무해·유해 입력의 분리가 뚜렷해지는 한편, 적대적 유해 입력이 무해 입력 쪽에 가까워지는 양상이 나타났다. 표현이 얼마나 다양한 방향에 퍼져 있는지 나타내는 유효 랭크(effective rank) 역시 후기 층에서 base 모델보다 낮았다(원문 Figure 7).

이 분석은 과신을 동반한 오류와 내부 표현 변화가 함께 나타남을 보여준다. 다만 표현의 압축이나 분리 구조가 오류의 원인임을 입증하는 인과 실험은 아니다.

Implications and Limitations

가드 모델을 평가할 때는 일반 입력의 정확도뿐 아니라 공격 입력에서의 보정 오차, 높은 확신을 동반한 미탐, 확신도 임계값을 바꿨을 때 남는 오류를 함께 살펴볼 필요가 있다.

이 연구의 기여는 실패 양상을 진단하고 base 모델에 남아 있는 불확실성 신호를 확인하는 데 있다. 그 신호를 활용한 새로운 보정 알고리즘이나 실제 배포 환경의 성능 개선을 검증한 연구는 아니다. 또한 일반 평가 집합은 유해·무해 입력을 모두 포함하지만 적대적 평가 집합은 유해 입력만 포함하므로, 결과는 이 평가 구성과 프롬프트 설정을 전제로 해석해야 한다.
